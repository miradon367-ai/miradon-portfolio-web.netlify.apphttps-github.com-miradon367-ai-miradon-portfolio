# Miradon Portfolio — AI Video Creation Expert & Full-Stack Developer

A futuristic, dark-themed, ultra-performant portfolio website for **Mira David don (Miradon)** built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, powered by a flat-file JSON/MD content architecture.

---

## 🌟 Key Features

- **Split-Hero Presentation:** High-impact two-column layout featuring kinetic skill pills, dual conversion CTAs, and a floating interactive 4K video teaser.
- **Cinematic Video Player Modal:** In-app video preview system for trailers (*The Mad Preacher*), commercial reels, and gameplay demos.
- **Project Case Studies (`/portfolio/[slug]`):** In-depth technical breakdowns with production pipelines, AI tools leveraged, engineering stacks, key challenges, and verified outcomes.
- **Interactive Appointment Booking:** In-app scheduler with date/time picker dispatching consultation inquiries directly to `miradon367@gmail.com`.
- **Flat-File JSON CMS (`/admin`):** Zero database latency, Git-versioned structured content for projects, profile bio, services, metrics, and testimonials.
- **100% Responsive & Accessible:** Fluid scaling across ultra-wide monitors, desktops, tablets, and mobile smartphones.
- **SEO & Social Optimization:** Dynamic OpenGraph metadata, JSON-LD schemas, sitemap, and robots.txt.
- **Netlify Ready:** Pre-configured `netlify.toml` for automated Git-based continuous deployment.

## 🚀 Quick Start & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Server Components, Route Handlers)
- **Language:** TypeScript 5+
- **Styling:** Tailwind CSS + Custom Cyber-Glass Tokens
- **Icons & Motion:** Lucide React, Framer Motion
- **Deployment:** Netlify
- **Data Layer:** Flat JSON (`/data/*.json`)
